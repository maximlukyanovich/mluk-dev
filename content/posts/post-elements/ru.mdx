Здесь собраны все элементы, которые можно использовать в публикации. В каждом разделе — элемент и то, как его записать. Исходник этой публикации, `content/posts/post-elements/ru.mdx`, — образец, из которого можно копировать.

## Текст

Абзац — обычный текст. **Жирный**, _курсив_, `код в строке` и [ссылка](https://nextjs.org/docs) пишутся как в любом Markdown. Сноска ставится сразу после утверждения, к которому она относится.[^footnotes]

- Пункт списка — строка, которая начинается с дефиса.
- Нумерованный список начинается с `1.`
- Пункты стоят плотно, абзацы — свободнее.

> Цитата начинается с `>`. Цитируйте чужие слова и называйте источник после цитаты.

<Note>
  Выноска — для правила, которое читатель не должен пропустить. Одна-две на
  публикацию, не больше: третью уже не замечают.
</Note>

## Код

Блок начинается с трёх обратных кавычек и названия языка. Имя файла пишется в `title`, подсвеченные строки — в фигурных скобках, подсвеченные слова — между косыми чертами:

```tsx title="app/[lang]/(site)/writing/page.tsx" {4} /getPosts/
import { getPosts, PostList } from "@/features/blog";

export default async function Writing() {
  const posts = getPosts(await getLocale());
  return <PostList posts={posts} />;
}
```

Другие языки записываются так же:

```css
.mk-prose h2 {
  margin-top: 48px;
  font-family: var(--font-display);
}
```

```bash
pnpm dev
```

Комментарий `// [!code --]` или `// [!code ++]` в конце строки помечает её как удалённую или добавленную. Кнопка копирования берёт только новую версию:

```ts
const theme = "light"; // [!code --]
const theme = "dark"; // [!code ++]
```

Блок длиннее 20 строк открывается свёрнутым, под ним — кнопка. Слово `nocollapse` после названия языка оставляет блок раскрытым.

## Картинки и таблицы

Картинка лежит рядом с публикацией, в её папке, и импортируется в начале файла. `<Figure>` принимает её вместе с описанием для экранных дикторов и подписью, если она нужна. Файл больше 1 МБ не пройдёт тесты.

<Figure
  src={home}
  alt="Главная страница mluk.dev в тёмной теме"
  caption="Главная страница. Нажмите на картинку, чтобы открыть её в полный размер."
/>

Таблица пишется в Markdown. Широкая таблица прокручивается внутри своей рамки, страница остаётся на месте.

| Элемент   | Как записать           |        Нужны скрипты        |
| :-------- | :--------------------- | :-------------------------: |
| Выноска   | `<Note>`               |             нет             |
| Картинка  | `<Figure>`             |    чтобы открыть крупно     |
| Видео     | `<YouTube>`, `<Vimeo>` |       чтобы запустить       |
| Блок кода | три обратные кавычки   | чтобы копировать и раскрыть |

## Видео

Видео подключается с YouTube или Vimeo по идентификатору. Пока читатель не нажал «Смотреть», страница ничего не загружает с сервиса. Без скриптов к видео ведёт ссылка в подписи.
